# Paper Reading System

## Published Reader Files

This directory stores released HTML reader examples.

Versioning rule:
- Each deployment is preserved as a new version.
- Existing released versions are not overwritten.
- File naming convention:
  - Version prefix first: `V0.7.6`
  - Remaining sections connected with underscores.

Example:
`V0.7.6_CANVAS_Cellular_architecture_and_neighborhood_informed_virtual_spatial_tumor_profiling.html`

## Release

Current release baseline: V0.7.6
